# 08 创新点与差异化定位

Type: grilling
Status: resolved
Blocked by: 01, 06

## Question

PRD自认"和BettaFish还是有点像，要再找出一些、设计一些新的内容"。基于BettaFish深度剖析和竞品扫描的结果，确定本项目的创新点与竞争力：哪些是真差异（别人没有的能力或体验）、哪些只是渐进改良？最终写成一个能在竞赛里讲清楚、也能支撑产品长期方向的差异化定位。

## Answer

用户决策（2026-08-12）：**第一卖点=可核验性——"可核验的舆情专报"，每个重要结论都能点回原文。**

差异化定位结构：

**核心主张**：claim级可核验引用体系——结构化引用（每个论断绑定来源）+ 自动核验 + 三级标记（已证实/待核验/争议）+ 证据留存（搜索结果原文快照，事后可回溯）。直击BettaFish最大痛点（issues实证"报告无来源可溯、幻觉高"）与Deep Research公认缺陷（错引真实来源、需人工逐条核验）；有现成学术方法（ALCE、VeriCite、NLI核验），可量化验收。

**支撑差异点**（按优先级）：
1. 结构化专报三件套：事件时间线 + 传播分析 + 历史相似事件对照——"历史对照"是BettaFish与Deep Research都没有的空档，由07的三层轻数据层支撑；
2. 零门槛C端体验：极简部署、免费搜索链默认可用、输入事件名一键出交互式HTML/PDF专报——收割被BettaFish部署门槛劝退的已验证用户群；
3. 技术创新叙事：异构模型分工+证据仲裁降幻觉（学术依据：同构多agent辩论不稳定优于单agent，arXiv:2502.08788）；合规轻数据层（可放心开源分发，对比BettaFish灰色爬虫依赖）。

**一句话区隔**：BettaFish是"重数据依赖、结论不可溯源"的舆情分析系统；本项目是"轻数据、全合规、每句话可核验"的C端舆情研究工具。

**竞赛叙事线**：4.2万star项目的442条issues证明需求真实且痛点明确 → 本项目以可核验性为灵魂重新设计 → 可量化验收（引用覆盖率/核验通过率可测）。
