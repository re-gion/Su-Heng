# 11 舆情专报样张原型

Type: prototype
Status: resolved
Blocked by: 01

## Question

拿一个真实舆情事件，手工做一份专报HTML样张（内容板块、可视化图表、风险/情感分级标注、引用呈现形式、交互），给用户实物反应，从而定下专报的内容规格与视觉标准。目标是明显超越BettaFish的报告形态。样张定型后，"专报里要有哪些内容"（是什么/为什么/怎么做、正负面客观分析、声量低但严重的问题等）就有了可执行规格。

## Answer

样张已交付并经用户评审定稿（2026-08-12）。

**资产**：`../prototypes/report-mockup-v1.html`（单文件92KB，海天"双标"事件，32条真实来源证据，Chrome实测通过）+ `../prototypes/report-mockup-v1-notes.md`（板块规格、设计决策、来源清单）。

**样张确立的专报规格**（十板块）：报告头KPI（示意/实计双标记）→ 执行摘要（WHAT/WHY/SO WHAT）→ 事件时间线（转折点标记）→ 关键事实核查表（核心板块：claim+核验徽章+引用卡片[来源/信源五级/日期/原文关键句/原文·转述标签/URL]）→ 传播分析 → 情感与观点+"声量低但值得注意的问题" → 历史对照 → C端研判建议 → 局限性声明 → 证据清单附录。视觉=新闻编辑室风格（暖灰纸底、单一墨蓝主色、语义色仅用于核验/情感、衬线标题+无衬线正文+等宽数字）。

**用户评审决议（五项，修订并增补既有决策）**：
1. **核验徽章升级为四级制**：已证实/待核验/争议/**已证伪**（新增，深红）——"证据充分否定流传说法"不再与"真正有争议"混用（修订10号票的三级制）。
2. **官方/标准文本级单源可直接判"已证实"**（卡片注明单源官方）；核验通过率指标口径按信源等级加权注明。
3. **传播图表改真实口径**：声量指数换成证据库真算的"报道数量时间分布/信源类型分布/平台视角分布"；新发事件叠加热榜快照真实数据；拿不到的不再画示意图（样张的示意+标注方式仅限样张）。
4. **"编辑判断"内容接受但硬规则隔离**：视觉隔离+"编辑判断"标签+不得进入执行摘要+计入局限性声明。
5. **报告IR支持速览/完整双版渲染**：速览版=摘要+核查表+结论（约2屏）默认展示，一键展开完整版。

样张遗留技术备忘（进SPEC）：正式版图表库需内联保证离线；中文衬线字体需子集化自带；样张v1不再迭代，规格增量以上述决议为准。
