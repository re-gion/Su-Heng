## 发现与已实施的对应关系

| 原有问题 | 本轮实际改变 |
| --- | --- |
| 证据附录占语义内容 77.9%，建议仅占 0.21% | 原文、核验矩阵与未引用材料折叠；摘要和正文保留决策相关内容 |
| 历史段落重复，论坛总结代替分析 | 移除论坛摘要的跨章机械复用，改为独立结构化分析；相同局限合并 |
| 原文与晚轮材料在输入截断时丢失 | 有界、均衡分配证据上下文，提供原文节选、来源、时间与已有陈述 |
| 建议泛化且引用随意 | 每项建议要求事实引用、影响、行动、建议责任职能、触发条件与不确定性 |
| 图表与事件理解无关 | 材料统计放审计层；事件时点从陈述明确日期提取；热榜同平台同话题分系列 |
| 数字可能被模型改造 | 来源披露值逐字匹配原文，绑定事件事实，保留单位；拒绝子串数字、单位换写和推荐流数字借用 |
| 报告模型空输出或审查串号 | 分章独立审查，候选分析显式编号，完整互斥判定；限定一次修订，失败时补一次逐条审查 |
| 原报告核验状态容易被摘要掩盖 | 摘要显示对应徽章，分析观察原文回填；未核验依据显式标注条件性 |

竞品的组织方式更成熟，但附件没有外部可回查引用，部分占比图数据合计为 215 和 168.2，不能直接作为数据标杆。上述判断只针对附件内部一致性，没有联网认定事件真伪或断言其数字造假。

## 真实回放结果

使用既有任务材料调用当前配置的报告与审查模型。因服务多次空输出，保留真实草稿、修订及审查结果，并在定位问题后复用已有草稿重新审查；最终产物不是一次无干预的全新在线调查。

最终 HTML 含 **5 条条件分析、7 个带引用的事件时点、164 条可展开证据记录**。量化披露值为 **0**：现有材料未满足原文、事件绑定及数值口径的共同要求。没有将证据条数冒充舆情规模，也没有抄用竞品指标。

模型原本放行 6 条分析。人工复读另移除 1 条：它混用提交材料与受理时间，并无依据推测议题降温路径。该漏判已记录在本地报告的审查元数据，并补入后续提示约束；不能据此宣称未来同类漏判已被完全消除。

`quality.status=analysis_available` 仅代表结构与依据检查下有可用分析及行动，不是“全部事实已证实”。语义审查总体仍为 `partial`，未审条目已移除，原有陈述仍保留原核验状态。

在 1440×1000 浏览器窗口、完整模式、附录默认关闭的相同条件下：

| 指标 | 原附件 | 改造后回放 |
| --- | ---: | ---: |
| 页面高度 | 120,541 px | 14,468 px |
| 附录高度 | 84,578.5 px | 3,895.1 px |
| 附录占页面高度 | 70.2% | 26.9% |

页面缩短约 88%，主要来自折叠审计材料和压缩重复，并不表示删除了对应证据，也不能单凭此数字认定分析质量提升 88%。

## 尚未被本轮证明的能力

1. 没有重新执行完整在线搜索与抓取调查，也没有新采集平台声量、阅读互动或登录评论样本。历史资料的核验欠账不会因重新排版消失。
