# 公开信息研究需求问卷编码与统计分析说明

本说明用于分析真实回收的答卷，回答哪些人有任务、现有做法有哪些困难，以及工具应优先解决什么。现在尚未回收数据，本文不包含调查结果；所有待填位置都应在正式收集后填写，不生成演示人数、比例或代表性结论。

## 一 先固定分析对象

| 分组 | 定义 | 用途 |
| --- | --- | --- |
| N_complete | Q00=A、正式版本、完成提交，且通过必要质量检查的答卷 | 描述参与者结构与所有人的预期需求 |
| N_recent | N_complete 中 Q03=B–F | 分析最近一次任务的行为、耗时与痛点 |
| N_no_recent | N_complete 中 Q03=A | 仅分析预期需求和概念意愿，不补填经历数据 |
| N_solo | N_recent 中 Q02=A | 描述近期有任务的独立接单或经营者；这是本调查的 OPC 相关分析分组 |
| N_ai | N_recent 中 Q06 选择 D | 描述在最近一次任务中使用通用 AI 的人 |
| N_time | N_recent 中 Q07=A–E | 描述能够估计主动投入时间的人 |
| N_finished_time | N_recent 中 Q08=A 且 Q07=A–E | 描述已完成任务的自报主动投入时间 |

Q01 的“独立研究者”和 Q02 的“独立接单或经营”不必一致；研究者也可能是机构员工，其他角色也可能独立经营。不要因二者不同删除答卷，不把 Q02=A 写成“全国 OPC 企业”。

同时保存各题的有效回答人数。结构性跳过、无法判断、记不清、不便透露和没有需求含义不同，不统一编码成 0。

## 二 变量与编码表

将固定选项 A、B、C……依次编码为 1、2、3……，保留原始值。下表列出分析名和特殊值；特殊值仍有原始选项编码，但在数值统计中须作为单独类别或缺失处理。

| 题号 | 分析变量 | 编码和用途 |
| --- | --- | --- |
| Q00 | consent | A=1；B=0，仅记录不同意结束数量，不分析其答卷 |
| Q01 | primary_role | A–I=1–9；I 为不便透露，不能归入无职业 |
| Q02 | work_arrangement | A–G=1–7；A 是独立接单或经营分组，G 为不便透露 |
| Q03 | recent_task_band | A–F=1–6；A 表示无近期任务，F 表示有任务但次数未知 |
| Q04 | latest_purpose | A–G=1–7；G 为记不清 |
| Q05 | intended_output | A–G=1–7；是主要计划结果，不代表已经交付 |
| Q06 | method_A…method_I | 多选分别编码 1/0；I 为整题记不清，不编码成所有方法未使用 |
| Q07 | active_time_band | A–F=1–6；F 为无法估计；分析使用档位，不能直接平均这些编码 |
| Q08 | task_status | A–E=1–5；B–D 均不是已完成任务，E 为记不清 |
| Q09 | pain_A…pain_K | 多选分别编码 1/0；J 是没有明显困难，K 是记不清 |
| Q10 | largest_time_stage | A–G=1–7；F 是没有明显最多环节，G 是记不清 |
| Q11 | consequence_A…consequence_J | 多选分别编码 1/0；I 是没有上述影响，J 是记不清 |
| Q12 | source_check | A–F=1–6；E 不适用，F 无法判断；D 不等于放弃核验 |
| Q13 | current_fit | A–E=1–5；F 保留为无法判断，不参与尺度统计 |
| Q14 | future_task_band | A–E=1–5；A 是预期 0 次，E 为无法预计 |
| Q15 | priority_A…priority_K | 多选分别编码 1/0；J 是暂时都不需要，K 是不确定 |
| Q16 | condition_A…condition_K | 多选分别编码 1/0；J 是暂无特别条件，K 是不确定 |
| Q17 | trial_intent | A–E=1–5；D/E 是在所述条件下的概念试用意愿 |
| Q18 | open_comment | 原始文本、脱敏文本与人工主题标签分别保存；空白不等于没有需求 |

多选题当选中“记不清”或“不确定”独占项时，其实质选项列应记为 NA，避免误当成所有选项都未选择。“没有困难”“不需要”“没有上述影响”等独占项则可把实质选项记为 0，但同时保留独占项列为 1。

“其他”的文字单列为 `Q09_other_text`、`Q15_other_text`、`Q16_other_text`。平台有额外题号时，根据题目及稳定选项 ID 映射，不依赖导出列顺序或随机展示的位置。每份答卷保留随机生成的 respondent_id、版本、渠道标签与完成耗时，不需要新增可识别身份字段。

## 三 清洗规则

正式发放前固定规则并保留处理记录，包括原始数量、排除数量及原因。不得因为受访者不喜欢 AI、没有需求、痛点不明显、来自高校或不愿试用而删除答案。

1. 不同意参与、测试答卷、未完成答卷和其他版本不进入 N_complete，分别记录数量。
2. 平台应阻止非法选项、超出多选上限以及独占项与其他项同选。导出后发现异常时，优先人工回看；无法恢复的题标记为 NA，不自动删除整份答卷。
3. Q03=A 时 Q04–Q13 全部视为结构性缺失，即使平台残留了旧值。Q03=B–F 时，必要的经历题缺失会影响该题的分析人数，须披露。
4. 重复答卷需要可靠的匿名平台记录或明确重复证据。共用 IP、相同选项或相似职业不能单独作为重复依据。不为查重额外收集手机号。
5. 答题过快只作为复查信号。应先根据试填实际耗时确定审查阈值，并结合题目缺失、非法作答或明显无关文字判断；不任意规定“少于某秒一律无效”。无经历路线自然更短，单独判断。
6. Q08=B 时主动投入时间很长，或 Q14=A 但 Q17=E，均可能合理：前者是进行中的复杂任务，后者是条件性试用意愿。不要机械判作矛盾。
7. 不编辑受访者的选择来使结论更好看。开放回答如出现身份、客户或保密信息，公开引用前先脱敏；不能可靠脱敏时只归纳主题、不公开原话。

## 四 建议先做的统计

### 样本结构与任务分布

列出 Q01、Q02、Q03 的人数和比例，先说明样本来自哪里。N_recent / N_complete 只是“回收样本中近期有任务的比例”，不是市场普及率。Q03=F 不赋予人为次数；频率使用档位分布。

### 最近一次任务的基线

用 Q04、Q05、Q06 展示任务目的、主要计划产物与现有工具组合。时间首先报告 N_finished_time 的档位人数及占比，并单列正在进行、搁置和放弃任务。无法估计人数单独显示。Q07 是回忆式自报，不是计时实测；不能与未完成任务混算平均总耗时，也不能把档位编码或任意中点算成“平均 X 小时”。

用 Q10 判断投入最多的环节，用 Q12 展示原始来源核对情况，用 Q13 展示现有方式的满足程度。Q13 可报告 A/B 的合计人数与比例，同时展示完整分布和 F 人数，不必把序数尺度加工成精确均分。

### 痛点及其实际影响

Q09 用各困难的选择人数排序。主展示分母为 N_recent，并单列“没有困难”和“记不清”；如另报可回忆样本的占比，必须改写分母名称。因为最多选 3 项，它测的是相对优先选择，不是每个困难是否曾经发生，也不是痛点严重程度量表。

Q11 同样列出具体影响、无影响和记不清。可以比较“选择某困难的人”中有多少同时选择“额外投入时间”或“未完成核对”，但这是自报关联，不能推断因果大小或损失金额。多选比例可以相加超过 100%。

### 需求优先级与采用条件

Q15、Q16 先分别展示 N_recent 和 N_no_recent，再在人数足够时展示 N_solo。不要把无近期经历者的功能想象写成真实工作痛点。Q15=H 的实时监测需求是产品边界外的需求信号，当前 README 明确该项目不提供全网实时监控；应记入扩展需求或定位取舍，不写成已有能力。

### 产品概念意愿

Q17 只描述看过统一文字介绍后的条件性试用意愿。分别报告完整五档分布，以及 D/E 合计人数。优先给出 N_recent 和 N_solo 的结果，注明分母。不能把它称作满意度、实际采用率、转化率、付费率或已实现的提效。

Q16=C 表示费用可控是采用条件，不等于愿意支付某金额。此问卷不估计市场规模、收入或具体定价。

### 开放回答

先读完回答，再按材料归纳主题，如来源、核验、交付、费用、部署、其他或无新增信息；保留未被封闭题覆盖的新主题。可一条多标签，跨标签人数不能相加。公开引用必须来自真实回答并完成脱敏，同时保留反对、无需求和不确定的理由。

## 五 比例的分母

选择比例 = 选择某选项的人数 / 明确命名的分析分组中具备该题有效记录的人数。

结构性跳过和被判定无法恢复的非法题不入分母。正常选了“记不清”“不确定”或“不需要”的答卷属于该题有效记录，主分布中保留这些类别。若报告排除“记不清”后的百分比，应同时给出排除人数和新分母，不能静默排除以抬高比例。

每张表或图至少写明：题号、分析人群、分母 n、人数、比例、是否多选及选择上限。小分组尤其要同时给人数，避免把个别人放大成稳定趋势。本轮建议 n 小于 10 的分组仅列人数并注明“人数较少”；这是一项保守展示约定，不是统计充分性门槛。

由于采用定向邀请和自愿填写，应明确这是非概率样本。未经额外抽样和模型论证，不给总体误差范围，不做全国总体推断，不把职业分组差异解读成代表性的市场差异。

## 六 比赛材料的空白结构

以下仅为正式回收后的写作框架。必须补入实际数值与日期；没有数据时保留待补，不把空白框架当调查结果。

> 我们于【实际起止日期】通过【具体渠道类型】定向邀请相关人员自愿填写 v1.0 问卷，回收【总数量】份记录。其中【同意并完成的数量】份进入主要分析，近期有实际任务者【N_recent】人，独立接单或经营且近期有任务者【N_solo】人。不同意、未完成、测试及其他排除情况为【人数与原因】。这是一组非概率样本，结论限于本轮参与者。
>
> 在近期有实际任务的参与者中，【困难选项】被【人数】人选为优先困难，占该题有效回答者【n】人的【比例】；另有【人数】人表示没有明显困难、【人数】人记不清。对应的自报影响包括【真实选项及人数】。这些数据支持我们优先处理【与证据一致的需求】，尚不能证明工具已经减少了耗时或错误。
>
> 阅读统一产品介绍后，【分析分组】中【人数】人表示大概或肯定愿意试用，占该题有效回答者【n】人的【比例】。采用条件集中于【真实选项及人数】；不愿意或不确定的理由包括【真实脱敏摘要】。此处反映产品概念意愿，实际使用效果与付费行为仍需另行验证。

建议比赛展示最多先做三张核心图：近期任务档位、前三项困难、采用条件。独立从业者人数足够时单列；不足时如实说明，保留为后续访谈方向。

## 七 后续验证

问卷用于发现需求。若要证明“溯衡”节省时间或改善证据核查，应另做真实任务对照：相近材料和交付要求、人工复核标准、实际主动工作时间、运行等待、费用、遗漏和错误记录分别测量。这些指标不能从试用意愿反推。

如需后续访谈，另设自愿报名入口及单独告知，不把联系方式关联到匿名问卷答卷。此轮没有收集或设计联系方式题。

方法边界参考 [AAPOR 调查最佳实践](https://aapor.org/standards-and-ethics/best-practices/) 和 [方法透明披露指引](https://aapor.org/standards-and-ethics/transparency-initiative/)。问题顺序与表述参考 [Pew 问卷设计说明](https://www.pewresearch.org/writing-survey-questions/)。上述执行人数与展示阈值为本项目建议，不是这些机构给出的通用要求。
