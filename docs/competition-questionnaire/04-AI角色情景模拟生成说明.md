# AI角色情景模拟生成说明

本说明对应2026年10月5日制作的SIM-v1情景材料。用户确认的交付范围是120条逐条标明AI模拟的记录与生成说明。真实问卷回收数保持为12份；本材料包不包含真人答卷，也不分析或扩大真实样本。

## 用途与解释边界

这些记录用于检查问卷跳转和数据处理、比较不同任务条件下可能出现的选择，并列出后续需要真实用户验证的假设。它们不是社会需求、采用率、付费率、满意度或提效的证据，不能与真人答卷合并统计，也不能称作新增回收的问卷。

40个角色和120个情境均由项目预先设计。角色配置、任务频率、流程成熟度和采用障碍不是人口抽样结果；没有总体权重、真实行为校准或有效样本量提升。增加记录数只增加设计情境的覆盖，不增加真实调查的证据量。

[AAPOR公开伦理规范](https://aapor.org/standards-and-ethics/)明确区分真人受访者和AI生成回答，并要求披露AI来源与生成方式。本材料据此公开来源，同时保持真实调查与模拟用途分开。

## 角色与情境

| 角色类别 | 虚构角色数 | 情境记录数 |
| --- | ---: | ---: |
| 独立研究者或分析师 | 10 | 30 |
| 一人咨询、传播服务工作室或独立顾问 | 10 | 30 |
| 独立内容创作者 | 10 | 30 |
| 企业或机构岗位人员 | 4 | 12 |
| 媒体人员 | 3 | 9 |
| 高校课程、教学或科研角色 | 3 | 9 |
| 合计 | 40 | 120 |

30个OPC相关角色的组织方式设为独立接单或经营。辅助角色覆盖机构独立岗位、小团队、大团队及非职业项目。全部为成年角色的假设，不填写真人姓名、联系方式、IP、单位名称或实际提交时间。

每个角色有三个独立情境：

- S1：高频、较复杂的公开信息研究任务，涉及多个来源、说法冲突或期限约束。
- S2：低频、较简单的任务。预先设置6个角色在该情境下无近期任务，以检查Q03到Q14的跳转；其余角色假定过去6个月有1–2次简单任务。
- S3：现有流程较成熟，或采用新工具受部署、费用、审批等约束。两个变体各覆盖20个角色，用于比较条件，不能解释为现实人群比例。

三种情境不是同一真人的随访，不计算重复测量统计。角色的行业主题、典型产物、原有工具和限制逐条写入角色设置表；生成代理进一步给每条记录写明任务假设和简短选择依据。

## 使用的问卷版本

SIM-v1沿用已发布稿的Q00–Q18题号与选项，作以下明确修订：

1. 一次任务须围绕公共事件或议题、有研究问题，并形成或计划形成具体研究产物；普通浏览或同一事件的反复查阅不额外算任务。
2. 概念介绍按当前README中的0.3.0公开预览版描述，补充自部署、配置模型与搜索服务、潜在调用费用、人工复核和材料不足时的报告降级。
3. 不承诺免部署托管服务，不把系统写成全网实时监控、总体民意测量或专业事实裁决工具。
4. Q00=A仅用于模拟分支，不表示获得任何真人知情同意；Q18的模拟开放回答也逐条带有“【AI模拟】”标识。

SIM-v1与已发布问卷的任务定义和概念介绍不同，不能把模拟版意愿与原版真实意愿直接比较。原问卷和12人回收文档保持原样。

## 生成与留痕

使用用户指定的GPT-6-Luna、medium推理配置。生成分A、B、C三个批次，分别覆盖14、13、13个角色，即42、39、39条记录，按代理会话上限分轮执行。不同批次使用同一模型配置，不能当作不同模型或独立人类判断的交叉验证。

指令不提供12份真实答卷的选择分布，不照其结果拟合，也不设定困难、需求或试用意愿的目标比例。不因不愿意尝试、没有需求或现有工具已足够而删除回答。每个生成批次保存指令、原始JSON、角色分配和输出校验信息；本轮生成文件另保存SHA-256校验值。

未固定随机种子，未取得服务端模型快照和完整采样参数，不承诺再次运行得到相同答案。保存的原始输出可以复核本次文件，但不能据此声称模拟已复现真人行为。

## 文件字段与使用方式

本地材料放在`output/competition-questionnaire/simulation-study-20261005/`，该目录按仓库原有规则不进入Git。生成说明进入仓库，模拟记录保持为本地交付产物。

| 文件 | 内容 |
| --- | --- |
| AI模拟记录_120条.csv | 可用Excel打开的UTF-8 BOM文件；包括题目代码、选项文字、角色与情境、模拟标识、选择依据 |
| AI模拟记录_120条.json | 保留数组、结构性空值和每条模拟元数据的结构化记录 |
| 虚构角色设置_40个.csv | 角色主题、典型任务、原有流程、约束和情境变体 |
| 题目与选项对照.csv | SIM-v1各题与选项代码的对照 |
| 模拟版问卷_SIM-v1.md | 本轮代理实际使用的填写工具 |
| 生成说明.md | 本说明的本地副本 |
| 生成与校验记录.json | 设计配置、批次、来源校验值、格式和逻辑检查结果 |
| 生成过程/ | 三个批次指令、原始输出与执行记录 |

CSV中的多选代码以分号分隔，如`A;C;F`；JSON中保留数组。Q03=A时Q04–Q13的CSV代码单元格为空，选项文字标为“结构性跳过（假定无近期任务）”，JSON为null；这不表示没有困难或数值为零。“记不清”“没有需求”等回答保留各自代码，不自动改为缺失。

每条记录的`dataset_kind`、`is_synthetic`、`synthetic_notice`、`instrument_version`均应保留。对外引用情境或开放回答时，标注“AI角色模拟示例”；不能把它们作为真人反馈、客户访谈或社会需求证明。

## 验证与剩余限制

交付前检查40×3覆盖、ID唯一性、题号与选项、多选上限和互斥、结构性跳转、角色一致性、模拟标识和CSV/JSON往返一致性；再核对每条情境与关键选择是否相符。具体是否通过以交付包中的校验记录为准。

这些检查验证文件可读取及内部规则是否成立，不验证现实中某类人会这样回答。模型可能带有表达趋同、知识覆盖不足或刻板假设；120条记录不是120名独立受访者，也不产生置信区间或市场需求结论。后续需向真实目标从业者核查情境、任务和采用障碍。
