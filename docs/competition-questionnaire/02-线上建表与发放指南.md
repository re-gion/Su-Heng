# 公开信息研究需求问卷建表与发放指南

本指南用于把 [问卷正式稿](01-问卷正式稿.md) 建成线上问卷。共 18 道主问题，其中 Q18 选填；Q00 为填写确认。近期有经历的人回答全部主问题，近期无经历的人回答 8 道主问题。5–7 分钟是设计目标，尚未经过真人试填验证。

## 一 先建表 再配置逻辑

平台展示标题使用“公开信息研究需求调查问卷”。照录正式稿开场说明，不把“帮助我们获奖”“支持创新项目”“大幅提效”等措辞加入标题、邀请或题目。Q17 前才展示产品介绍；在需求题之前不放演示视频、产品截图、成果案例或效率宣传。

按正式稿的顺序创建题目。题目编号 Q00–Q18 用于核对和导出，可保留在题目开头。以下类型是通用建表要求，不表示某个平台能够自动解析这份 Markdown 或纯文本。

随机展示只调整展示次序，不改变选项的导出编码。若平台不支持部分选项固定在末尾、稳定编码或随机展示，保留正式稿顺序并在方法说明中披露；不要手动给不同渠道随意改版本。

“其他”文字默认选填、最多 80 字，且不得变成选择该项后必须提供身份信息。Q01、Q02、Q04–Q06、Q11 的“其他”可以直接作为选项保留，不需要再加追问题。

## 二 页面与跳转

建议分成五个页面：

1. 开场说明、Q00、Q01–Q03。
2. 最近一次任务说明、Q04–Q07。
3. Q08–Q11。
4. Q12–Q13，然后是第三部分说明、Q14–Q15。
5. Q16、项目简要介绍、Q17–Q18、结束语。

核心路线：`Q00=A → Q01–Q03 → Q03=B–F 时 Q04–Q13 → Q14–Q18 → 提交`；`Q03=A → Q14–Q18 → 提交`；`Q00=B → 未同意结束页`。

以“条件显示 Q04–Q13”实现无经历跳转时，应连同该部分说明一起隐藏。支持直接跳到 Q14 的平台则配置页面跳转。不得让被隐藏的必答题阻止提交。

把 Q03 从有经历改成 0 次时，清空 Q04–Q13 的旧值；恢复有经历后允许重新回答。如果平台无法清空，分析时严格按最终 Q03 将该段旧值判为结构性缺失，不参与统计。变更多选独占项时，也应清空同题的其他选择。

Q00=B 的结束页显示：“本次填写已结束，感谢您了解本调查。”该路径不保留后续答案、不计为有效答卷。若平台不能关闭这种路径的记录，仅统计其数量，不分析或导出个人记录。已同意后退出的未完成答卷不进入主要结论。

## 三 平台设置

- 关闭姓名、手机号、邮箱、单位、精确地区、微信昵称等身份题；关闭平台可选的实名登录和通讯录授权。
- 关闭面向受访者的实时统计，避免先前回答影响后续选择；不要公开原始答卷。
- 优先使用无需登录的匿名填写模式。平台自带的 IP、账号或设备信息可能仍按其规则处理；检查隐私设置，不承诺“绝不留下任何网络记录”，不把这些字段作为公开分析数据。
- 可提醒同一人只填写一次。不要仅按 IP 删除重复答卷，专业社群或办公室可能共用网络。
- 只保存必要的答题耗时与非识别性的渠道标签，用于试填和方法披露。若渠道标签不能配置，则在发放记录中记渠道与日期，不追加身份题。
- 原始答卷导出后放在本地受控目录（例如 Git 已忽略的 `data/survey/`）；不得提交仓库或随比赛材料公开。比赛材料仅放汇总表和脱敏摘要。

正式发放前，应在所选平台实测以上设置。此交付没有创建线上链接，也没有操作问卷平台账户。

## 四 发放对象与招募

优先定向邀请独立研究者、咨询或传播服务从业者、内容创作者、媒体人员以及机构内部研究或传播岗位人员。允许相关高校人员和暂无近期任务的人真实填写；分析时按角色和经历分别展示。

建议招募来源至少涵盖研究咨询、媒体内容、机构传播三类渠道，并特别关注 Q02=A 的独立接单或经营者。这里的分组是招募覆盖目标，不是对总体职业分布的估计；不补造答卷，也不为了让比例好看强行配额。

可先以 30–50 份“同意、完成且近期有实际经历”的答卷作为首轮探索性工作量目标。这个数量是本项目执行建议，不是统计代表性或样本量充分性的证明。获取困难时如实报告实际数量和样本结构，不用一般学生或无经历者代替 OPC 从业者。分组人数较少时只呈现人数及个案线索。

### 可复制的邀请文字

您好，我们正在为 AI+OPC 比赛中的“溯衡”项目做需求调研，想了解公开信息研究中的实际工作方式和困难。若您会为研究、内容制作、咨询或工作判断查找公开材料，欢迎填写这份匿名问卷。问卷以 5–7 分钟为设计目标，没有近期经历也可如实回答。不需要姓名、单位或联系方式；无论是否使用 AI、是否需要这类工具，都欢迎真实意见。请同一人只填一次。

问卷链接：发布后补入。

邀请文字可由项目组自行发送；本次制作未代为发送或联系任何受访者。

## 五 小范围试填与冻结

建议先邀请 5–8 位目标人群试填，至少包含独立从业者、其他相关岗位人员、没有近期任务的人。人数是工作建议，不保证能发现全部问题。记录以下事项：

- 对“公开信息研究任务”的理解，是否把随手浏览也算作任务。
- 能否稳定回忆最近一次任务，时间档位和角色选项是否有遗漏。
- Q09、Q15、Q16 是否难选，是否频繁需要“其他”。
- 手机端能否看清选项，无经历路线是否正确跳过，退出或返回修改是否出现残留值。
- 实际完成耗时的中位数与范围；开放回答耗时单独留意。

如果完整路线明显超过目标时长，先删减不关键的选项或调整说明，再复测；不要在没有记录的情况下宣称已经验证“5 分钟完成”。小范围试填答卷不并入正式数据，尤其是修改过题目时。

试填后锁定题目、选项编码、跳转和清洗规则。正式版本标记为 `v1.0`，记录实际发放日期与平台。收集中若必须修改，另建版本并分别统计，不混为同一份问卷。

## 六 上线前检查清单

- [ ] 开场说明和 Q17 前的产品说明完整、中性，与当前 README 一致。
- [ ] Q00=B 能结束，Q03=A 能提交，Q03=B–F 显示完整经历题。
- [ ] Q03 往返修改后没有被跳过题目的旧答案污染统计。
- [ ] Q06 的 I，以及 Q09、Q11、Q15、Q16 的两个独占项均不能和其他项同选。
- [ ] 受限多选最多 3 项，所有选填文字可以留空。
- [ ] 随机顺序不会改变导出编码，尺度与时间档位保持有序。
- [ ] 项目介绍在 Q16 之后，产品意愿不与需求事实混在一起统计。
- [ ] 手机端和电脑端各完成一遍有经历、无经历、不同意路线。
- [ ] 导出文件包含稳定题号、原始选项值和版本信息；身份类平台字段不进入公开材料。
- [ ] 完成真人试填并填写实际时长、问题及修订记录。

## 七 方法参考

题目中性表达、一次测量一个概念以及对问题顺序的控制，参考 [Pew Research Center 的 Writing Survey Questions](https://www.pewresearch.org/writing-survey-questions/)。试填、明确样本来源和公开方法限制，参考 [AAPOR 的 Best Practices for Survey Research](https://aapor.org/standards-and-ethics/best-practices/) 与 [Transparency Initiative](https://aapor.org/standards-and-ethics/transparency-initiative/)。本问卷是项目需求调研工具，未经过量表效度验证。
