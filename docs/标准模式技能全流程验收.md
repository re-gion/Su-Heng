# 标准模式技能全流程验收与修补

## 验收口径

2026-11-15，使用本机有效模型与搜索配置，围绕“2023年江西工业职业技术学院食堂异物事件的官方调查与处置”运行真实标准任务。没有缩减标准预算：总 token 上限 1,400,000，搜索 75 次、抓取 70 次、陈述 60 条、证据关系核验 150 次、论坛最多两轮。评论全部关闭。

八类角色的目录和绑定均检查；无评论任务实际应运行任务准备、事实调查、媒体传播、历史洞察、协作主持、证据核验、综合报告七类角色。评论洞察应显示“未启用”，不能为了宣称八角色覆盖而执行评论采集。已沿用用户调整后的“综合报告 Agent”名称。

任务使用独立 SQLite 文件和运行目录，避免开发服务重启影响任务；搜索和抓取配额继续使用本机实际账户台账。有效密钥仅保留在进程内，没有复制到测试数据库或提交到仓库。浏览器检查使用已完成任务的本机只读副本，不能启动模型任务。前六轮使用 `zh,en`，第七轮及后续使用 `zh` 集中检查中文独立案例；均为标准深度、无评论。

## 实测发现与修复

| 问题 | 修复及保留的边界 |
| --- | --- |
| 年份中的“年”被并入机构名，补充工作说明也进入事件身份判断 | 去除查询中的日期前缀；范围判断统一使用保存的事件名称，补充说明继续用于规划；报告传播节点复用相同的主体识别规则 |
| “食堂……异物”等分散概念被连续短语匹配漏掉 | 对短复合概念要求多个组成词同时出现；单独“食堂”等泛词不能放行另一件事 |
| 历史席输出当前事件普通事实，或把案例字段放在顶层 | 每条陈述独立提供案例身份；缺少独立身份、机构不见于引用来源的候选不入库；外文机构保留原文身份锚点 |
| 背景标选被同义改写，连带丢失事实 | 将可选背景字段与事实分开处理。保留符合独立身份和来源要求的事实，仅接受正文中真实存在的标选；至多一次背景修订，不改事实正文。缺少背景继续作为待补线索 |
| 餐厅身份等同于“发生何事” | 泛指机构或人物的名词不能单独满足案例事件背景；案例仍须交代核心事件与关键进展 |
| 隐私审查重复改写“一名学生”，或把机构、日期一起删掉 | 保留已有匿名称谓；拒绝跨越机构、日期或整句的姓名删改。更新审查缓存键，继续保留已有个人标识与别名保护 |
| 摘要句子类型与引用不匹配，反馈难以定位 | 明确段落职责与句子类型分别判断，给出具体位置和类型契约；事实、分析、局限各自绑定真实依据 |
| 一处不合格候选句使其余摘要全部丢失 | 第二次草稿仍存在可精确定位的无依据数字、内部术语或重复句时，可仅移除这些候选句。四段、长度、引用检查仍须通过，随后重新完整审查逐句支持、段落职责与重大遗漏；不通过仍降级 |
| 回溯句中的事件日期被当作通报日期 | 已有未注明日期的“通报称”“表示”等动作，或日期只是“关于”“截至”的对象时，不据此推定动作日期。原陈述和引用留在事实表，不以网页日期补齐 |
| 历史板块被最终审查移除，页首仍显示“已完成” | 根据最终保留内容撤销过时的完成状态；旧报告只读回放也修正展示，不改原始事实、徽章和数据库历史记录 |
| 同一案例使用相近名称，重复计为独立对照 | 对同主体、同一材料月份且名称高度相近的项，保留一项正式对照，其余作为身份待确认的补充线索；不自动合并事实，不认定必然同案，保留不同事件和不同月份的材料 |
| 未经内容复核的章节提醒进入局限性和摘要 | 不再发布自由格式 `section_warnings`，只记录诊断数量。这些模型提醒不能代替经过核查的材料范围或事件局限 |
| 多数据库连接初始化时重复删除重建唯一索引 | 在写事务中检查、按需迁移旧索引；当前结构不再每次重建，保留唯一性约束与并发配额检查 |

任务页同时补全“次模型请求”及审查未完成、陈述额度用尽的中文说明。模型接口请求数、技能处理记录条数、模型选用记录数继续分别统计。

## 最终可审阅版本

第八轮任务实际加载七个活跃角色的技能，产生 244 条处理记录；15 条为模型选用，其余为沿用或工作单匹配。逐条检查角色白名单、版本、文件指纹、共享方法和加载顺序，没有发现错误。评论角色没有执行。

最终本地清理版报告为 `983bb3f987474d868e1ec5616dfa8341`，原在线候选 `ab5eddb36d834916808385fc2f061e40` 保留。清理版保留 30 个时间线节点、5 项正式历史对照和 24 个媒体发布节点；未证实具体转载/回应关系，不补造连线。

人工复核发现，模型章节提醒曾把某章所引材料的范围扩大为整份报告的采集截止范围，并使“责任处理未见材料”与已取得的企业处罚材料产生歧义。代码已停止将这类未审查提醒作为正式局限和摘要依据，847 项回归通过。当前报告移除了 7 项此类提醒；原摘要因此不能继续沿用旧审批，清理版明确降级为事实提要。

拟用现有模型重新生成摘要并进行完整内容与隐私审查，但自动审批拒绝：用户的在线实测授权没有明确覆盖“这份具体既有报告发送到该具体模型主机”，无直接个人标识检查也不足以证明报告派生内容不敏感。复审未执行，未产生额外模型请求，未通过其他路径重发。待用户明确授权后，才可执行这一步。清理版的 HTML、PDF、证据包均已在本地导出供审阅。

因此，本轮完成了代码修补、标准流程运行、七角色技能加载和本地交付检查；**尚未完成完整答辩演示验收**。最后的摘要复审仍待授权，传播关系的证据缺口也继续保留。

## 解释边界

当前配置中多个角色使用同一模型，独立角色复核不等于异构模型交叉验证。技能加载记录证明请求使用了登记方法，不证明每个候选都被采用，也不证明准确率提升。

外部模型曾连续连接失败，随后匿名基础地址检查和合成 JSON 检查恢复正常；这不能证明中转服务已经稳定。传播图不能用同主题、同日或相似正文冒充转载关系；没有通过具体关系审查时只保留发布节点。摘要若未通过结构、引用、语义或隐私审查，继续显示事实提要，不伪装为已完成的四段执行摘要。

测试数据库、原始响应诊断、报告和截图属于本地产物，不通过 Git 同步。本轮未验收评论登录采集，也未部署到公网。
