# 报告阅读导航设计

2026-10-14 与维护者确认的阅读页方案：左侧固定层级目录、右侧报告正文，配色与调查台一致。

## 布局与交互

- 桌面目录固定在工具栏下方，宽 268 px，使用浅色背景与系统蓝当前项。目录独立滚动，可收起；正文在剩余区域居中，最大宽度保持 1120 px。
- 二级目录来自报告正文中可见的主要小节标题。与章节名称重复的隐藏标题、具体陈述、分析卡片和证据卡片标题不进入目录；没有主要小节的章节无需展开按钮。
- 阅读进入新章节时自动展开该章的小节、折叠其他章节；用户可以手动展开其他章节，或收起当前章。仍在同一章内滚动时保留手动展开状态。
- 点击章节或小节可定位并生成可分享的锚点；刷新和浏览器前进、后退仍可定位。普通滚动更新目录及正文当前状态，不改写 URL。
- 保留整章阅读边框，改为淡蓝色，与当前章节同步。证据引用继续展开并突出对应证据卡，保持原有回查能力。
- 宽度不超过 1000 px 时，正文占满可用宽度，通过“目录”按钮打开左侧抽屉。选中条目、点击遮罩或按 Escape 后关闭；抽屉打开时限制背景操作，关闭后焦点回到目录按钮。
- 工具栏换行、缩放和窗口调整后重新计算目录顶部及定位留白。速览只展示对应章节及小节；切换完整版时恢复目录条目。
- 打印及 PDF 隐藏导航、遮罩和阅读边框，正文不保留侧栏空白。

## 实现边界

导航从确定性渲染后的结构标题生成，随单文件 HTML 内联交付，不依赖网络，不增加模型调用。已有报告通过系统报告页重新渲染即可获得新导航；已经另存的 HTML 文件需重新导出。报告 IR、数据库事实、核验徽章和引用关系保持原有契约。

本次属于可逆的阅读界面调整，记录在本文，不新增架构 ADR；通用界面术语不加入领域词汇表。

## 验收要求

真实浏览器覆盖桌面固定目录、二级目录生成与展开、长章节上下滚动、小节定位与刷新、速览切换、证据跳转、390/820 px 抽屉及键盘焦点、工具栏换行与打印。另以已保存报告 IR 进行确定性回放和截图检查，区分阅读页验证与新的线上调查验收。
