# ADR-0009：评论问题驱动证据对照与有限补查

日期：2026-10-03。状态：整体设计已由用户确认，问题组织与有限补查已实现；真实覆盖和剩余限制另行验收。

现有评论流程以固定议题和立场分组，综合评论主题时要求同时给出风险、回应缺口与建议，但并不向主题审查传入事件证据。用户选择围绕当前事件的具体评论问题组织观察，将不同观点、理由和诉求并列呈现，并对照公开证据；固定议题与立场仅作辅助标签。这一取舍将评论从分类结果变成发现调查遗漏、解释分歧的入口，也增加了问题归纳与证据关联的要求。

用户同时确认允许将一条评论中的多个观点或诉求拆为多条观察，分别关联相关问题，并始终保留原评论与必要语境。以去重评论样本数描述各问题覆盖，整体统计中同一评论只计一次；问题之间可能重叠，不能将各问题样本数相加作为整体数量。这能保留“认可处理但要求公开程序”这样的复合表达，但不能把多个观察解释成多个人的独立意见。

当已有材料无法回答可核实的公共事件问题时，允许在原任务总预算内挑选少量高价值评论取证线索，定向补查公开来源并沿用事件证据核验流程。相比仅标注材料缺口，这能补充报告内容，但会增加耗时及调用成本；不得因为评论中的说法或出现频次而跳过公共性、隐私、来源与核验要求，不得把评论本身作为事件事实证明。首版最多三个问题、每个问题一轮补查；按可核查性和信息价值优先、频次辅助排序，沿用搜索、抓取、陈述和核验额度。实际未调用的预算跳过可恢复；已执行的问题不重复补查。

沿用 ADR-0008 的分层交付：补查未完成或未找到答案时，保留仍然有效的已审评论观察，并诚实说明缺口；“现有材料没有回答”不能写成“相关机构未曾回应”，没有取得公开材料也不能据此判定评论所述事实为真或为假。评论阶段使用剩余任务预算的八成，预留其余部分给最终发布审查，不增加默认总预算。新任务启用此流程，旧报告维持原有事实与审查边界。

2026-10-04 修订：默认速读在核心报告恢复后执行。其内部另预留剩余额度的40%、最多40,000 token给问题摘要及独立审查；总任务上限不变。归纳问题时同时起草短摘要，按问题逐项批量复核，单项失败不抹去其他已审内容。新增关联索引尚未通过问题审查时，旧摘要继续限定原有不变样本，新索引保持待归纳；新问题通过后才替换对应旧摘要。原话回查与关键词检索为只读操作。见[同材料修复验收](../20261003-专报与评论修复验收.md)，全量处理仍未通过。
