# ADR-0007: 公开事件调查范围与普通个人隐私保护

状态：已采纳（2026-09-28）；替代 2026-09-27 的新任务默认机构范围取舍，保留旧任务语义。

两份真实任务表明，仅允许机构回应会排除必要事件背景、公开司法结论和传播争议。审查服务失败又被布尔值当成内容拒绝，造成已有合格材料在报告中整体消失。增加预算不能解决这些问题。

新增 `public_event` 范围：调查公开事件全貌，包括必要背景、公开司法及机构结论、媒体传播和有出处的争议分析。普通个人以任务内稳定的角色称谓匿名化；禁止挖掘私人信息、把私人指控写成事实或从评论推断身份。明确公共事件自动采用这一范围；只有公共事件与私人纠纷的边界不清时才请求确认。明确人肉或私人指控请求仍拒绝。

`institution` 继续表示只调查机构回应、处理及相关公开讨论。已有任务不静默升级；恢复程序在独立数据库副本中明确记录来源任务、策略版本和新范围。标题保留经隐私审查的具体事件名称，报告等级独立展示。

范围审查返回通过、拒绝、未完成，并单列原因。预算不足、连接故障、上游异常和格式错误属于未完成，不是违规。按内容和策略版本保存通过或明确拒绝的结果；未完成项可恢复。按条目、章节隔离问题内容，已经通过的事实和摘要不会因可选分析审查失败而整体清空。脱敏只允许原字符串到限定角色称谓的替换，不增加事实。改写后的陈述及分析必须重新核验，不能沿用原徽章或支持关系。

公开来源链接保留；未经脱敏审查的原文、快照及原始引用不进入此范围的报告或证据包，快照 API 仍关闭。原始材料留在受限本地数据库供核验使用。评论仍默认关闭、只处理已确认帖子，样本不代表总体民意。

预算是上限。每批陈述先保存检查点；按材料指纹和分析目标复用处理结果，恢复先审未完成批次。一个逻辑调用的网络、输出长度及格式重试合计最多三次实际请求，输出上限不超过 32768。阶段保留额度继续生效；评论隐私审查另给分类和综合留出空间。报告组织、传播关系和章节语义审查最多使用进入报告阶段时余量的四分之三，最后四分之一保留给最终隐私审查；未使用额度不强制消费。固定数量小批次分类避免一次截断就需要预留 32768 输出额度。无有效进展或核心要求已完成时停止；审查故障不触发新取证或整份报告重建。

调用诊断、预算预留、排队/请求时间和任务状态计时持久化。旧日志缺失的上游原因、请求耗时与计费组成保持未知，不从总历时推断供应商速度。真实恢复和新调查分别验收；自动测试通过不代表线上调查质量已达标。
