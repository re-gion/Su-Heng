# ADR-0008：评论观察与评论研判分层交付

日期：2026-10-03。状态：整体设计已由用户确认，分层交付已实现；真实生成效果及限制另见验收记录。

现有评论主题同时绑定观点、理由、风险和建议的审查结果，某个建议或引语失败可能使整个主题失去产出。用户确认改为分层交付：先呈现逐项通过来源、语义及隐私审查的评论观察，风险和处置建议作为评论研判另行审查；研判未通过，不连带清空仍然有效的已审观察。相比必须形成完整主题才展示，这一取舍能保留已经取得的材料价值，但不能把仅完成分类的标签或未经审查的摘要当作合格观察。

本决策细化 ADR-0006 与 ADR-0007 的独立产物与审查边界，不改变事件事实核验、隐私规则或整份报告的核心发布门。某条依据被移除或改变时，依赖它的产物仍需重新审查；无关且依据有效的观察保留。沿用此前确认的“画像与处置建议都要，处置优先”；建议缺失时必须明确说明，不能把观察当成已完成研判。

具体问题也先按全部关联观察独立审查并保存，再进行公开证据对照与研判。对照调用失败或额度不足时，已审问题与观察继续展示，并标明对照尚未完成；后续明确发现问题本身不成立时，仍移除该问题。恢复保留归纳候选及已审问题，不因一次可选分析失败重新归纳全部样本。

评论按具体问题组织、多条观察关联同一原评论、对照公开证据及有限补查遵循 ADR-0009。新任务使用分层流程；旧报告与旧检查点保留兼容，不自动重写。
