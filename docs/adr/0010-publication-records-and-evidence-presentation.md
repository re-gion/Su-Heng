# 发布记录与实质事实分别核验

已取得原文并核验为支持的转载材料，过去因不计入独立信源而被汇总为“无有效证据”；同一条陈述在事实核查显示单源支持，在时间线却显示待核验。2026-10-04 的真实报告审计还发现，通报核心动作与落款细节绑在同一句，导致有据可查的主要内容随附加细节一同降级。

经用户确认，区分“机构发布了什么、文件记载了什么”与“文件中的指控是否属实”。发布机构身份必须由登记的域名归属确认，取得目标页面正文、快照和哈希，绑定证据全部核验完成且无反证或矛盾，才允许按机构原文确认发布记录。媒体转载、未知发布者、搜索服务正文及搜索摘要均不能走这条例外。

独立信源计数仍按主体归并。转载的支持关系保留，但不增加独立互证计数；阅读层分别说明单源支持、转载支持、来源身份待确认、部分支持、依据不足和核验未完成。摘要、事件时间线和事实核查使用同一条数据库陈述的证据说明。历史报告仅投影其保存的证据状态，不重新判定徽章或发布等级。

生成阶段发现通报内容与落款等独立断言混合时，退回重新提取短陈述；不在渲染阶段截掉未获支持的半句。此决策细化 [ADR-0002](0002-scope-first-investigation-and-report-release-gates.md) 的事实门，报告完整性门、隐私审查、反证和核验失败处理保持有效。

分析卡片中由已审查陈述原文精确拼接的观察也是权威回填，不能在后续报告审查中再次由模型改写。只保护引用完整且正文精确匹配的回填；生成的解释、影响、建议等文字仍须审查，无法对应权威陈述的观察仍由 R19 拒绝。
