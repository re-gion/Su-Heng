# ADR-0002: 范围先行调查与报告发布门

**Status**: Accepted
**Date**: 2026-09-21

## Context

宽泛的“机构名＋舆情”会把同一机构下不同时期、不同性质的事件混入一次深入任务。过去语言、时间和国内优先仅作为提示词，搜索结果仍可把外文、范围外和离题材料写入主证据；系统随后对这些材料逐条核验并生成长报告，既增加等待时间，也会把材料不足包装成完整舆情专报。

媒体传播席位过去只有自然语言 claim，没有可验证的发布节点和传播关系，因此容易退化为事实调查的复述。智能选帖在 Windows 的 Selector 事件循环中启动 Playwright 子进程时还可能失败，并被空列表掩盖。

## Decision

1. 宽泛主题先进入 `topic_selection`：系统展示有公开来源支撑的候选事件簇，由用户选择或手工填写后再深入调查。事件发现的具体置信、恢复检索与手工预检规则由 ADR-0003 细化。
2. 主调查把语言选择视为硬允许列表；“国内优先”第一阶段只接收境内来源，明确高优先级证据缺口存在时才进入带标签的境外补充阶段，境外材料可保留原始语言。
3. ~~显式日期范围是主证据准入窗口。页面可见日期或可信结构化日期未确认、或落在窗口外的材料不能支持当前事件主陈述和时间线；历史对照仅进入第 06 章。~~ 此项由 [ADR-0005](0005-agent-boundaries-and-investigation-time-window.md) 取代。搜索 provider 返回的日期仍只作为待核验提示，不据此提前淘汰或放行材料。
4. 媒体传播输出结构化 `publication_node` 和 `propagation_edges`。少于两个有效节点或没有可追溯关系边时，章节明确标记证据不足。
5. 报告使用三档发布标签：`full_report`、`evidence_brief`、`retrieval_diagnostic`。基础事实门未通过时跳过分章模型调用，只生成检索诊断。
6. 深入模式是预算上限，不要求跑满；连续两轮没有新增有效主证据即停止。核验采用有界并发，报告分章先并行处理 07、04，再并行处理 05、06（执行顺序以核心契约为准）。
7. 智能选帖候选为空时暂停一次，显示逐平台诊断并允许补充 URL 或明确跳过；Playwright 公开发现固定运行在独立 Proactor 事件循环。

## Consequences

- 用户会多一次具体事件确认，但避免把多个事件混成一份报告。
- 日期范围的后续取舍见 ADR-0005；必要的窗口外本事件材料须标明日期与越界原因，独立历史事件仍与本事件时间线分开。
- 一部分过去能生成“完整报告”的任务会降级为证据简报或检索诊断；这是质量门的预期结果。
- 境外补充不会被中文白名单误伤，但必须等国内阶段暴露明确缺口后才启动。
- 真实任务的模型调用量应显著下降；极端情况下，分章并发仍可能受到上游并发限制，失败章节仍按原有规则独立降级。
