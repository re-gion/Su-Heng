# 用元宝替换 LangSearch，并分离地域与语言决策

状态：已采纳（2026-11-05）。细化并部分取代 ADR-0004 中当前搜索主源和原始语言补充规则；历史实测不追溯改写。

用户反馈 LangSearch 结果质量差，要求删除适配器并比较元宝的 MCP、Skill 与 Python SDK 接入。同时确认本次实现自动地域分类：国内优先，境外、跨境、不明从首轮混合，显示理由，可手动覆盖；语言为明确允许列表。元宝保护线确认为每任务 60 次、每月 3000 次，管理员可调。

采用官方 API Key HTTP，通过现有异步 SearchProvider 接口接入。MCP 和 Skill 面向宿主工具编排，不提高底层搜索质量；同步 SDK 增加线程与签名依赖，当前无必要。复用现有补源、预算、熔断、域名筛选和诊断。元宝摘要不标记全文；原 LangSearch 日期重试退出执行链，旧密钥不再使用、历史记录保留。

地域决策持久化于任务独立字段，不占用调查恢复检查点。模型仅输出类别、置信度和理由；代码将高置信国内映射为 domestic，其余映射为 global。手动范围优先，恢复复用输入指纹，主题选事件后重算。此决策不改变隐私门禁、证据等级或徽章。

检索词翻译与跨语言同主体/同事件判断分开，翻译本身不能证明主体别名；只接受材料逐字存在的别名，匹配限当前材料，后续仍受确定性守卫。原有自动扩英文与历史专项强插中文一并移除，避免绕过允许列表。中英文事件发现轮转分配查询，英文聚类要求具体事件关联，避免同校不同事件误合并。

本地限额按实际尝试预留、失败不退、暂停恢复保留；月度连接测试也计数。它不是云账户限额，不能控制其他部署或其他服务的费用。没有真实 WSA Key，本次不声称线上质量提升已验收。参数、价格与替代方案证据见[接入调研](../元宝搜索接入与多语言检索.md)。

2026-11-05 补充：按用户要求，标准/旗舰改为 `Mode=2` 混合结果，接收有可回查来源的网页与垂直结果，均保持搜索摘要身份；无有效 URL 的卡片不入库。极速不支持 Mode。认证明确采用服务 API KEY（Bearer），不是腾讯云 SecretId/SecretKey 标准签名方式；standard 仅指套餐版本。
