# V2 评论插件与国际信源使用指南

## 启用

评论插件只适用于本机直接运行，不在 Docker 演示站提供：

```env
YUQING_COMMENT_PLUGIN_ENABLED=true
YUQING_COMMENT_BROWSER=C:\Program Files\Google\Chrome\Application\chrome.exe
```

浏览器路径可省略，系统会尝试发现 Chrome 或 Edge。每个平台使用独立 profile：`data/browser-profiles/<platform>/`。

## 使用流程

1. 在配置中枢启用插件，逐个平台打开专用登录浏览器并自行登录。
2. 新建任务时选择智能、指定 URL 或混合评论模式。
3. 三路公开调查完成后，任务暂停在“评论候选确认”；即使系统候选为空，也不会静默跳过。
4. 检查候选理由、评分、逐平台发现结果和原帖，勾选后开始采集；空候选时可补充帖子 URL，或明确跳过。
5. 系统先完成核心报告的核验与发布审查，再从通过隐私审查的样本中提取观点、理由、诉求及追问，按具体问题对照公开证据。风险和建议另行审查，未通过时保留有效观察。

机构范围调查仍可由用户主动开启评论深挖。系统在主题分析前逐条筛选，只采用关于机构公开回应与处理的评论；涉及普通个人指控或范围无法确认的评论不进入分析，报告列明排除数量。筛选失败时按未采用处理，不能把未筛选样本当作机构舆情结论。

智能选帖只在用户确认具体事件之后运行。它使用已确认事件以及调查中形成的陈述与证据标题构造帖子检索词，再通过一次性、无 Cookie 的浏览器读取各平台公开搜索页；它不负责从宽泛主题发现事件。候选必须同时通过目标平台域名、帖子 URL 形态和主题相关度校验；公开搜索页没有结果的平台才会回退到通用搜索 provider。通用 provider 返回的站外链接会被本地硬过滤，不能进入候选列表。

发现候选阶段不会读取 `data/browser-profiles/`。用户确认候选后，系统会在后台逐个平台检查专用 profile 中是否有登录 Cookie，检查结束即关闭临时浏览器；未登录的平台仍会在开始采集前一次列出。正式采集时才打开可见浏览器，同一时刻最多运行一个自动采集窗口；每个帖子完成、失败或停止后都会关闭该自动窗口，登录信息仍保存在各平台 profile 中。用户从配置中枢手动打开的登录浏览器不会被自动关闭。若所有渠道都没有发现达到门槛的候选，系统会显示每个平台的“发现/为空/失败”状态与简短原因，并暂停一次。用户补充帖子 URL 后可以继续采集，也可以明确跳过评论洞察；系统不会静默跳过，也不会无限等待。

## 评论产物与恢复

默认速读为每条合格评论建立简短的问题、理由、诉求索引，在具体问题下生成一次摘要并配代表原话。任务完成后，页面可展开全部关联原话、待归类的已审索引，按关键词搜索全部合格样本；这些浏览操作不新增模型调用。问题摘要生成与独立审查的依据包含全部关联索引，代表引语只是阅读入口。

报告分别展示采集量、已审有效样本、索引、问题和建议数量。一条评论确有多个观点或诉求时可以拆分并关联不同问题；整体样本数去重，不能把问题样本数相加或推断总体民意。未归类或未完成归纳不影响已审原话的回查；待审原文、候选索引和自由文本拒绝理由不进入页面与报告。

点击问题下的“对照已有材料”才启动该问题的证据对照及可选条件性研判。打开页面、展开原话和搜索不会启动深挖。对照公开材料仍有缺口且问题可公开核实时，页面提供单独的“开启公开补查”按钮；最多三个问题、每个一轮，共用原任务剩余模型、搜索、抓取、陈述与核验预算，不额外大范围采集评论。额度不足、未找到新材料、审查拒绝或未完成分别说明，成功结果更新原报告的评论部分，已有核心事实保持。报告已下线复核时禁止调用和读取。

速读、样本审查与深挖分别显示进度；未开启深挖不导致合格速读降级。局部失败保留其他已审内容，可从本地进度恢复，原警告保留。有效复用绑定样本、范围、提示词与材料指纹，公开材料变化后旧证据回答失效。旧报告不会自动重写，需重建才采用新的默认流程；旧版已审问题仍可点选深挖。评论能力仍只开放本机，Docker 和 Demo 环境不开放深挖。

## 多语言

- 主调查把用户选择的 BCP-47 语言当作硬允许列表，而不是最低覆盖要求。
- “国内优先”先只使用境内来源；存在明确高优先级证据缺口时，下一轮才可进入“境外补充”，并允许使用来源原始语言。
- 境外补充材料在报告中单独标注；境外查询按配置默认顺序 `Exa → Tavily → Serper`，再按实际额度、失败和来源覆盖情况降级。Exa 注册赠送 $20、之后每月 $10，Tavily 每月 1000 credits，Serper 的 2500 次免费额度为一次性；这些是供应商当前公开口径，不是本项目已完成的在线质量验收。
- 搜索 Provider 返回的全文可帮助筛选和阅读，但不等于本地直接快照；需要逐字引用和复查时仍优先尝试直接抓取，内置抓取失败后才对关键页面使用 Firecrawl Cloud。
- 报告使用中文，但证据卡始终保留外文原文；“机器翻译”不参与逐字引用核验。

## 安全与故障

- Cookie 不写入 SQLite、API、日志、报告或证据 ZIP。
- 不绕过验证码、登录墙、付费墙与风控；遇到验证立即停止该平台。
- 不保存昵称、头像、账号 ID 或关系链；任务内评论 ID 为不可逆哈希。
- 评论只代表用户确认帖子的采集样本，不代表平台整体或全网民意。
- `COMMENT_LOGIN_REQUIRED`：打开该平台专用浏览器并登录。
- `COMMENT_RISK_CONTROLLED`：出现验证码或访问频繁提示，本次采集会停止。
- `COMMENT_PLUGIN_LOCAL_ONLY`：只能从 `127.0.0.1` 或 `localhost` 的同源页面操作。
