## 含义与配色

两道折返路径围住中央菱形，结合回溯与榫合的意象。中央橙色“榫芯”代表共同核查的证据，周围空白保留不同调查路径的独立性。此寓意不代表所有结论都已证实。

- 主色：深墨蓝 `#172B4D`。
- 强调色：琥珀橙 `#EAA332`。
- 中文字标：Noto Sans SC 轮廓排印，已转为路径，接收方无需安装字体。

## 使用规则

保持比例，不拉伸、不旋转主体。标志外围建议留出至少主体宽度 1/6 的空白；画布现有空白可计入。标准横版组合建议宽度至少 160 px；16–32 px 场景优先用 favicon 专用版。橙色用于证据核心，避免把整个图形改为橙色。
