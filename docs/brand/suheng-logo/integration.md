# 回溯之榫 Logo 接入记录

## 接入范围

- 首页页眉、设置页、页脚：使用用户选定的 A 方案，中文为轮廓字标。
- 浏览器图标：SVG 与包含 16/32/48 px 图像的 ICO；图标链接带品牌版本参数。
- HTML 报告：封面字标与浏览器图标内嵌为 data URI，单文件离线可显示。
- PDF 与证据包：复用报告渲染器，使用相同品牌资产。
- PDF 缓存：以渲染内容摘要区分版本，旧缓存不再遮住更新的品牌；同一渲染结果仍复用缓存。
- 项目 README：展示定稿 Logo。

前端资源位于 `frontend/src/assets/brand/` 和 `frontend/public/`；后端资源位于 `backend/yuqing/render/assets/`，由 `brand.py` 随包读取。更新品牌资产时，从 `final/` 同步到这两处；前端组合字标由 Vite 生成内容哈希文件名。

2026-09-30 已清理首版及第二轮三稿，保留 final/、本接入说明及前后端已使用的资源。定稿预览页、说明和交付包已同步为当前保留范围。

## 历史接入验证

- 后端：376 项 pytest 通过；Ruff check、format check 与 import-linter 通过。
- 前端：16 项 Vitest 通过；typecheck 与生产构建通过。
- 实际启动隔离的本地 FastAPI 服务，使用生产前端构建和离线报告夹具。
- 实际 Edge 浏览器检查首页、设置页、1440 px 桌面及 390 px 手机布局：品牌图片成功加载，无横向溢出、无页面脚本异常。
- favicon SVG 与 ICO 均返回 HTTP 200，媒体类型正确。
- HTML、PDF 与证据包端点均返回 HTTP 200；连续下载 PDF 命中同内容缓存。
- HTML 在禁用网络的浏览器上下文中仍能显示品牌。证据包内 HTML 的品牌图标已内嵌，SVG 可解析。
- 使用实际 Chromium PDF 导出器生成 PDF，以 Poppler 渲染并查看第一页：品牌图形与字标正常。未逐页复审报告的既有分页布局。
- 回归覆盖旧 PDF 缓存失效、新缓存复用及模板变化后的重新导出。
- 实际构建 Python wheel，核对包内 SVG 与定稿完全一致，并在隔离 Python 路径下直接从 wheel 导入资源成功。

本轮是本地界面与交付链路验收，未进行真实模型、搜索服务、评论平台或公网部署验收。已有一条 Starlette TestClient 的上游弃用提示，不影响测试通过。
