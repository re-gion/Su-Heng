# 八类 Agent 的专项技能与运行记录

系统使用八类 Agent 身份与一份只读方法目录。角色配置卡、运行请求和任务记录都从同一目录取得技能信息；新增卡片不等于新增执行权限。

| Agent | 模型角色 | 主技能 |
| --- | --- | --- |
| 任务准备 | `utility` | 调查范围识别与准备 |
| 事实调查 | `analyst_a` | 事件事实链重建 |
| 媒体传播 | `analyst_b` | 报道口径追踪 |
| 历史洞察 | `analyst_c` | 可比案例与机制对照 |
| 评论洞察 | `comment_analyst` | 评论样本问题与诉求归纳 |
| 协作主持 | `moderator` | 缺口诊断与定向协作 |
| 证据核验 | `verifier` | 陈述与证据对照核验 |
| 报告综合 | `reporter` | 证据约束的专报综合 |

## 方法目录

Agent 定义位于 `backend/yuqing/agents/definitions/`，新增 `description` 与 `main_skill` 字段。方法包位于同级 `skills/`，共 15 项专项方法与 3 项共享基础方法。每份包声明名称、适用角色、版本、适用工作阶段、预期产物；正文说明输入、步骤、工具边界、停止和降级条件。原有三份共享技能已经扩展为完整方法说明。

`GET /api/agents` 返回八类角色、主技能、允许的专项与共享技能、完整方法说明和内容指纹，不返回文件路径、模型连接配置或密钥。配置页可以查看方法，不能上传、编辑或切换到未登记方法。方法目录随进程加载；修改本地方法文件后需要重启后端。版本与内容指纹进入实际调用记录；调查摘要检查点也包含方法目录版本，避免升级方法后直接沿用旧方法的生成缓存。

## 真实运行方式

三类调查席在规划与反思之前，先取得技能索引，使用一次独立、计入现有预算的结构化模型调用选择允许的方法。程序检查选择与角色白名单，然后把选中方法正文及该角色的共享方法交给执行请求。总结沿用本轮所选方法。反思输入包含已入库材料概况；第一轮只有主题时，不得声称已经发现材料冲突。

事实席可选事实链重建、冲突陈述对照和证据缺口补查；传播席可选口径追踪、转载与回应关系追踪；历史席可选机制对照、可比性审查。选择格式不合格或越出白名单时，记录程序回退及原因，再使用本角色的基础方法。模型预算不足仍执行原预算停止规则。

主持、核验、报告、评论和任务准备按当前工作单类型加载对应方法。这些角色在方法内部进行结构化判断，不宣称每次加载均是模型自主选择。核验工作单加载陈述证据对照，其他审查工作单加载表达依据审查；跨语言检索准备与材料翻译有独立方法。

技能通过现有 JSON 协议与程序执行器工作，当前没有增加供应商原生工具调用循环，也不宣称模型自行执行了 `read_skill`、搜索或数据库写入。所有搜索、抓取、入库、访问控制和结果校验仍由原有服务执行。

## 记录与展示

使用现有持久化 `agent.status` 事件，增加 `kind="skill"` 与 `skill` 对象，不变更数据库事件类型枚举。记录包括调用 ID、角色、方法 ID、版本、内容指纹、工作阶段、简短选择理由、选择方式和真实状态。

状态依次为 `selected`、`loaded`、`running`、`response_ready`，失败或取消分别为 `failed`、`cancelled`。`response_ready` 只说明模型返回 JSON，不能表示业务校验、原文核验或入库完成。

调用方保存调查摘要、主持评审、陈述核验或最终报告后，补充 `stage_saved` 或 `stage_partial` 与阶段产物引用。**阶段引用描述所在阶段已保存的产物，不表示每次模型候选都被采用，也不构成每次调用到某条陈述的一对一贡献归因。** 核验工作单另外关联实际陈述与证据编号；最终徽章继续由代码计算。

配置页展示已登记技能。任务页展示八类角色、最近方法、可按角色筛选的执行记录及阶段证据/报告链接；较早调用可继续展开。现有 SSE 的 seq 去重和历史补放用于刷新恢复，技能事件不覆盖普通调查阶段。旧任务不补造记录，未参与的角色如实显示未参与；评论关闭时明确标为未启用。终态缺少调用结束记录时显示这一限制，不继续显示为正在调用。

## 保持的边界

- 核验 Agent 不挑选有利材料、不跳过绑定证据、不计算最终徽章、不更改独立信源计数。
- 报告 Agent 不改写数据库的权威事实、徽章、引用或指标，材料不足仍按发布门降级。
- 公共性与隐私门禁是强制流程，不能因技能选择而跳过。
- 评论插件仍默认关闭，Docker 与 Demo 保持禁用；用户确认和样本边界不变。
- 同源模型不伪装成异构核验；Skill 数量和调用次数不构成准确率提升的证据。
