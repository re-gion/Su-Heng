# 元宝搜索接入与多语言检索

调研日期：2026-11-05。当前代码已用元宝替换 LangSearch；没有本账号密钥，尚未执行真实元宝调用、召回对比或生产部署验收。

## 接入方式的选择

| 方式 | 官方入口与认证 | 本系统的取舍 |
| --- | --- | --- |
| HTTP API | `POST https://api.wsa.cloud.tencent.com/SearchPro`，Bearer API Key | 采用现有 `httpx.AsyncClient` 和 `SearchProvider`；能复用异步、限流、额度、重试、筛选和诊断 |
| MCP | `https://api.wsa.cloud.tencent.com/Mcp`，Streamable HTTP、SearchPro | 适合给桌面 Agent 配工具；仍是同一搜索能力，不能改善索引或召回，服务端引入 MCP 客户端没有必要 |
| Skill | 官方提供 Agent 调用说明与脚本 | 适合人工研究工作流；不作为部署后端的运行依赖 |
| Python SDK | `tencentcloud.wsa.v20250508.WsaClient.SearchPro`，SecretId/SecretKey 签名 | 官方可用，但同步接口需要移出事件循环，并新增认证与 SDK 依赖；现有异步 HTTP 更直接 |

依据：[API Key 文档](https://cloud.tencent.com/document/product/1806/130615)、[MCP](https://cloud.tencent.com/developer/mcp/server/11764)、[AI 工具/Skill](https://cloud.tencent.com/document/product/1806/140541)、[SDK](https://cloud.tencent.com/document/product/1806/121802)、[官方 Python SDK 源码](https://github.com/TencentCloud/tencentcloud-sdk-python/blob/master/tencentcloud/wsa/v20250508/wsa_client.py)。

## 配置与迁移

在管理设置页填写元宝 Key，选择账户实际开通的版本，保存后运行连接测试。也可设置环境变量：

```dotenv
YUANBAO_API_KEY=
YUANBAO_VERSION=standard
YUANBAO_MAX_CALLS_PER_TASK=60
YUANBAO_MAX_CALLS_PER_MONTH=3000
```

采用腾讯云控制台的**服务 API KEY 方式**：在“概览 > 服务 API KEY 方式”创建 Key，填入 `YUANBAO_API_KEY`。这是 Bearer Key 接入；腾讯云标准签名接入使用 SecretId/SecretKey，本适配器不接收该密钥对。`YUANBAO_VERSION=standard` 仅表示标准版服务套餐，与接入认证方式无关。支持官方变量 `TENCENTCLOUD_WSA_APIKEY` 作为 Key 别名。配置优先级保持 SQLite 设置、环境变量、默认值；已有 LangSearch Key 不再调用，也不会转换为元宝 Key。历史报告和事件中的 LangSearch 标签保留。数据库增加独立 `source_scope_resolution` 字段，启动时兼容旧库，不改写旧报告。

每次上游尝试先原子预留额度，失败、重试也计入；任务计数跨暂停/恢复保存。元宝月度限额覆盖连接测试；达到上限不再请求元宝，继续其他已配置补源。其他搜索、模型、其他数据库或部署的费用不在该上限中。计数不是腾讯账单或余额。多进程共用 SQLite 可共享计数；间隔限流仅覆盖当前应用进程。

极速、标准、旗舰公开按量价为 14、20、26 元/千次；按标准版，3000 次约 60 元。账户版本、资源包和活动实际权益须在控制台确认，版本设置不购买或升级服务。参考：[计费](https://cloud.tencent.com/document/product/1806/121798)、[产品介绍](https://cloud.tencent.com/document/product/1806/121794)。

## 现在怎样搜索

语言决定搜索服务组，地域决定材料准入范围，二者独立：

| 维度 | 当前行为 |
| --- | --- |
| 中文查询 | 元宝 → Exa → 千帆 → 博查，只用已配置服务 |
| 其他语言查询 | Exa → Tavily → Serper；整组均未配置才回退另一组 |
| 国内优先 | 首轮境内来源；有明确高优先级缺口时后续轮境外补充，仍只用允许语言 |
| 国内外混合 | 首轮允许中外来源，仍受语言、主体、事件、时间与预算守卫约束 |
| 自动地域 | 高置信国内事件→国内优先；境外/跨境/未知/低置信/分类失败→混合 |
| 手动覆盖 | 用户明确选择 domestic/global 时直接采用，不调用自动分类模型 |

自动分类使用受现有模型预算约束的 utility 调用，根据事件发生地、主体和处置范围判断，不能用输入语言推断地域。保存分类、理由、阶段、输入指纹和实际范围；相同输入恢复复用，宽泛主题选定事件后重新分类。分类只影响检索政策，不改变公共性门禁、事实徽章或证据权威等级。

主调查筛选后候选发布主体不足两个时补源；历史对照按案例规则取材。URL 去重与发布主体多样性不等于独立事实互证。语言选择为硬允许列表，境外补充和本地历史也遵守。主题发现按语言轮转分配首轮机会；服务错误和翻译失败不能算完成语言覆盖。

检索词与目标语言不一致时单独翻译，失败则记录未覆盖，不只修改 `lang` 标签。跨语言主体匹配单独读取原始问题和实际材料，要求高置信同主体、同事件、且别名逐字存在；查询翻译自身不能证明别名。材料仍须通过其余确定性守卫并抓取核验。当前新增回归主要覆盖中英文，其他语种尚无同等在线验收。

## 元宝特有的边界

- `Response.Pages` 是 JSON 字符串数组；HTTP 200 中的业务错误仍算失败。
- `passage` 与 `content` 均是摘要，保持 `search_snippet`，不冒充网页全文、直接快照或可逐字引用的原文。
- 标准/旗舰显式使用 `Mode=2` 混合模式（公开网页与优质权威垂直信源）；极速不支持 Mode，无法切换此模式，仍不发送 Mode/Cnt。有可回查 HTTP(S) 来源、标题和摘要/结构化 display 的垂直结果保留为搜索线索，无有效来源的卡片不入证据库。域名筛选同样约束垂直结果，返回卡片不自动提升本地来源等级或核验状态。Cnt 按官方十条档位上取整，本地按 top_k 截断。
- Site 多包含域保留本地并集筛选；多排除域使用官方管道符，所有返回仍本地校验。
- 相对日期与单日支持上游过滤。官方日期范围文字与样例顺序有歧义，目前不猜测传参，使用页面日期核查；保留搜索原始日期和来源标记，日期不能仅凭摘要确认为权威。
- 不支持微信公众号内容，尚未看到分页/offset 契约。需要公众号原文时须由其他合法渠道补源，不能承诺元宝全覆盖。

依据：[SearchPro](https://cloud.tencent.com/document/product/1806/121811)、[FAQ](https://cloud.tencent.com/document/product/1806/121804)。

## 验收方式

离线测试检查请求参数、结构错误、摘要/全文区分、日期、域名、额度原子预留与恢复、分类缓存与重分类、双语覆盖和同主体不同事件拒绝。真实验收仍须配置账户 Key，用同一组中文、境外、跨境事件和固定日期对比主源有效结果、原文可取率和补源增量。成功连接只证明返回可用网页，不能证明搜索质量达标。

2026-11-05 实际验证：后端全量 649 通过、2 失败；两个失败均为报告目录滚动用例，已在原版 88b2cd5 重现。最终相关回归集覆盖配置、调查循环、自动地域、多语言、配额与并发预留，单独运行全部通过。前端 6 个文件共 32 项测试通过，typecheck、build、ruff check/format 与 import-linter 通过；9 份相关文档本地链接检查通过。元宝在线调用、真实模型地域分类准确率和生产部署均未验收。

混合模式补充验证：元宝适配器、搜索链与配置接口共 41 项测试通过，覆盖标准/旗舰 Mode=2、极速参数省略、垂直 display 解析、无来源卡片拒绝及本地域名约束；ruff check/format 与差异空白检查通过。仍未进行真实元宝在线调用。
