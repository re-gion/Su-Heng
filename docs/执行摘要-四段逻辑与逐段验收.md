# 执行摘要四段逻辑与逐段验收

2026-11-14。本轮把执行摘要从自由编排调整为固定职责的四段叙述。目标是首次接触事件的读者在2—3分钟内理解主线、当前状态、分歧、主要判断及判断边界。此前摘要及分段标题功能的记录保留为历史，以本页和核心契约的IR 0.12约定为准。

## 新摘要行为

| 顺序与角色 | 系统固定标题 | 本段承担的信息任务 |
| --- | --- | --- |
| 1 / event | 事件概况与当前进展 | 起因、关键转折、当前状态；不能直接从末期处置起笔 |
| 2 / dispute | 核心争议与已知回应 | 各方具体分歧、已有回应及仍存问题；不能被处置细节占满 |
| 3 / findings | 主要研判与依据 | 重要判断及依据、含义；不能重复前两段时序 |
| 4 / limits | 局限与后续关注 | 重要边界、会改变判断的新材料和后续关注；不首次堆入早期背景 |

先调用摘要规划，为四段分别选择主旨、三类依据引用和材料可用性，再写正文。主旨是临时写作数据，不进入报告或缓存；固定标题及材料可用性由代码回填，不采信草稿自行提供的值。正常摘要通常600—900字，原有每段10句、全文24句/1400字符等硬限额保留。

争议或研判材料不足仍保留该段，直接说明可确认什么、缺什么及不能据此判断什么，可自然缩短；不能编造双方意见或机制判断。连事件主线都无法可靠交代时，规划阶段即回退事实提要。摘要审查同模型等方法说明保留在局限性章节，不放入新摘要写作材料；其变化仍会使完整依据校验值失效。

审查不再只要求全局主题出现过。每段的职责匹配、主旨集中和必要缺口披露均须完整通过，同时检查跨段重复及末段背景倒灌。任何缺项、非布尔审批或拒绝都不能发布；保留至多一次修订机会，修订反馈包含具体段落、句子、覆盖项及原稿。规划新增一次调用，写作和内容审查各最多两次，继续受现有阶段预算和总额度约束。

逐句事实/分析/局限引用、数字和单位依据、隐私范围审查、事实提要降级及完整专报发布门保持有效。失败只发布受控诊断，不公开未审草稿、规划主旨或自由文本审查理由。模型语义审查并不能保证每份摘要都正确。

### 2026-11-16 摘要修订保留跨段去重
